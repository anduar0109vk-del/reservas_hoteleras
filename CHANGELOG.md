# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-10-19

### Added

- Hotel reservation management for clients, reception, management, and administrators.
- Room availability, reservation creation and tracking, check-in, and check-out.
- Payments and room services associated with reservations.
- Detailed PDF receipts and reservation reports in PDF, Excel, and CSV formats.
- Complaint tracking, customer chatbot, WhatsApp contact, and light/dark themes.
- Frontend lint and production build checks in GitHub Actions.
- Unit tests for missing and invalid reservation dates.

### Changed

- Updated the repository and frontend setup guides to match the actual project layout and local development workflow.
- Made frontend lint non-mutating so validation does not change source files.

### Resolved

- Resolved the README title merge conflict by retaining a single canonical project title.
